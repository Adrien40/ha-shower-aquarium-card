# Security Policy

## Supported versions

Only the latest release receives fixes.

## Scope

This card runs in the browser, inside Home Assistant. It only reads the states of the entities it is configured with. It does not call services, make network requests, or store data.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private reporting instead: go to the **Security** tab of this repository and click **Report a vulnerability**
(direct link: <https://github.com/Adrien40/ha-shower-aquarium-card/security/advisories/new>).

Include the card version, the Home Assistant version, and steps to reproduce. You will get an answer as soon as possible, and the fix will be credited to you if you wish.
